# 篩檢多一步，落差少一點

> **教學虛構｜非官方統計｜全數為電腦生成的聚合資料｜不含個人資料｜不得對外引用**

本資料包以國民健康署近期推動的「健康臺灣—擴大癌症篩檢」為政策背景，供三階 AI 簡報課程練習使用。案例中的示範區 A–D、示範據點 A01–D02、服務數字、調查、訪談、資源與成本全部是教學合成內容，不代表任何縣市、醫療院所或國民健康署實際成果。

## 真實與虛構的界線

- **官方事實：**只採用 [`00_官方來源導覽.md`](00_官方來源導覽.md) 所列國民健康署公開網頁，並保留原始網址。
- **教學虛構：**F01–F09 的執行資料、區域差異、方案情境及未查核初稿。
- **無個資：**沒有姓名、聯絡方式、生日、地址、病歷、院所真名或可回推個人的小樣本紀錄。
- **不可外用：**不可將本資料包的數字、分析或圖表對外引用為政策現況或官方統計。

## 三階使用路徑

1. **第一階｜從資料來源到可信初稿**  
   先讀官方來源，再用 F01–F08 建立來源清單、數字台帳、可引用主張及 6 頁迷你大綱。
2. **第二階｜從 AI 初稿到可提報版本**  
   查核 F09 的未查核草稿；重新確認版本、分母、人次／人數、百分比／百分點及限制。
3. **第三階｜從政策訊息到主管決策溝通**  
   使用 F08 比較三個未核定情境，呈現證據、取捨、風險與待確認事項；資料包不提供指定答案。

## 檔案地圖

| 類型 | 檔案 | 用途 |
|---|---|---|
| 導覽 | `manifest.json` | 機器可讀的檔案清單與聲明 |
| 官方來源 | `00_官方來源導覽.md` | 3 個國健署來源及可用邊界 |
| 資料 | `F01`–`F08` | 版本、漏斗、月份、可近性、試辦、調查、訪談與資源情境 |
| 草稿 | `F09_未查核_AI初稿.txt` | 第二階查核材料，不是答案 |
| 模板 | `T01`–`T04` | 空白來源表、數字台帳、事實核對表及方案比較表 |

## 使用提醒

- CSV 為 UTF-8 編碼；Excel 匯入時請選擇 UTF-8。
- 每筆合成資料都含 `data_status=教學合成資料`。
- `F02` 同時保留 v1 與 v2，兩版不可混用。
- `F03` 的「服務人次」與「估計不重複人數」不可互換。
- `F05` 為無對照組的前後期觀察，不能單憑資料宣稱因果。
- `F06` 僅代表回覆者，多選題百分比總和可能超過 100%。
- `F08` 是未核定的教學情境估算，不是預算或政策承諾。

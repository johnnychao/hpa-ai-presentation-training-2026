# ImageGen production prompts

All four project assets were generated with the built-in ImageGen path. The
shared visual system is a professional 3D clay-and-paper miniature diorama in
deep forest green, muted teal, ink navy, warm cream, and restrained amber.
Every prompt explicitly excludes text, logos, seals, watermarks, identifiable
faces, medical-cross symbols, branded interfaces, neon colors, and purple
gradients.

## `hero-workshop.png`

- Use case: `stylized-concept`
- Asset: wide 16:9 landing-page hero
- Scene: an anonymous public-health-office workshop with miniature adults
  collaborating around a laptop and abstract presentation board
- Composition: the diorama is weighted right, leaving clean headline space on
  the left
- Materials: matte clay, cut paper, lightly grained wood, and soft fabric

## `stage-foundation.png`

- Use case: `stylized-concept`
- Asset: 4:3 course-stage card
- Scene: anonymous learners sort trustworthy source cards and organize blank
  slide panels into a clear first-draft sequence
- Style reference: the hero asset

## `stage-refinement.png`

- Use case: `stylized-concept`
- Asset: 4:3 course-stage card
- Scene: anonymous learners compare layouts, reorder a story, inspect evidence,
  and improve abstract charts
- Style reference: the foundation-stage asset

## `stage-decision.png`

- Use case: `stylized-concept`
- Asset: 4:3 course-stage card
- Scene: an anonymous presenter and listeners compare options, risks, and
  decision points in a miniature briefing room
- Style reference: the refinement-stage asset

The PNG files are retained as editable source assets for future bitmap
reprocessing. The matching WebP files are the production website assets.
